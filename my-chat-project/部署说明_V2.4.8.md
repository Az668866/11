# 拓界云客服 v2.4.8 部署说明

## 这次升级会不会清空数据库

不会。后端首次启动时会增量创建 `tenant_frontend_templates`、`auth_sessions`、`auth_attempt_limits`、`license_generation_requests`、`data_protection_state` 及其索引，并把每个租户当前使用的模板写入历史名单；不会删除租户、会话、消息、卡密或 R2 文件，也不需要手工执行 SQL。

数据库快照或备份仍建议在正式升级前创建，它只用于部署故障时回滚，不是程序运行的必要条件。

## 环境变量

本次新增一个必须谨慎迁移的变量。首次升级时，先读取当前正式环境的真实 `TOKEN_SECRET`，把同一个值复制到 `DATA_PROTECTION_SECRET`，然后保持两个值不变部署新后端：

```env
APP_VERSION=2.4.8
TOKEN_SECRET=升级前的原值
DATA_PROTECTION_SECRET=与升级前_TOKEN_SECRET_完全相同的值
```

其余数据库、R2、Telegram、Cloudflare、TURN、Web Push 等环境变量全部沿用。第一次启动成功并验证历史卡密、TOTP 和语音前，尤其不要重新生成 `TOKEN_SECRET`。完整密钥轮换顺序见 `DEPLOYMENT_SECURITY.md`；填错数据保护密钥时后端会安全停止启动，禁止删除校验表绕过。

## 推荐上线顺序

1. 必须给 PostgreSQL 创建部署前快照，并保留当前三套部署包与环境变量加密备份。
2. 在隔离数据库运行 `npm run test:integration`，并按 `load/README.md` 完成必要容量验证。
3. 按上一节复制数据保护密钥，先部署 v2.4.8 Render 后端并确认 `/health/ready` 正常；启动时自动完成增量建表。
4. 验证历史卡密、管理员 TOTP 和历史语音；旧的管理员、代理和租户令牌升级后失效，需重新登录。
5. 再部署新的超级管理员、代理、租户后台和各用户端完整静态目录。
6. 打开超级后台“租户管理”，检查试点租户的“允许访问的历史模板”。
7. 分别从当前模板、历史模板和一个从未批准的测试域名验证访问结果，并完成消息与语音/视频通话冒烟测试。

当前只允许运行一个应用实例；在线状态与 SSE 事件尚未接入共享事件总线，不能直接横向扩容。上线门禁、源站保护、MFA、监控和回滚要求分别见 `DEPLOYMENT_SECURITY.md` 与 `ROLLBACK.md`。

## 历史模板规则

- 升级后：租户每次在租户后台选择并保存模板，系统只做一次参数化 `UPSERT`，旧记录不会被覆盖。
- 可以继续访问：该租户曾经选择过、Origin 与模板 ID 同时匹配、并且平台状态仍是“已启用”的模板。
- 仍然拒绝：从未选择过的复制站点、Origin 与模板 ID 不成对、或被平台紧急停用的模板。
- 每个模板使用一个共享 Netlify 域名，租户通过网址中的 `tenant` 参数识别；模板切换后要重新保存二维码。
- 该功能没有轮询、没有定时扫描；日常读取复用租户配置缓存，模板切换时才增加一次小型写入。

## 升级前已切换的租户

系统会尝试从尚未被清理的“租户本人成功保存设置”审计记录恢复旧选择。为了安全，来源异常告警绝不会自动变成批准记录。

如果某个租户升级前已经从 `wxmb5` 切换到 `dymb1`，但旧审计已被清理：

1. 超级后台进入“租户管理”。
2. 找到该租户，点击“设置”。
3. 在“允许访问的历史模板”中同时勾选微信模板（`wxmb5`）和当前模板（`dymb1`）。
4. 点击“保存”。

保存后不需要让租户再次切换，也不需要修改二维码。

## 公告发布

超级后台进入“公告管理”并点击“发布公告”，建议填写：

- 标题：`用户端模板切换兼容升级通知`
- 类型：`版本更新`
- 范围：`全部租户`
- 展示方式：`横幅和弹窗`
- 强制弹窗并统计已读：勾选
- 开始时间：立即
- 自动下线时间：建议上线后 14 天

公告正文：

> 平台已完成用户端模板切换兼容升级。升级后，租户曾经实际选择并保存过、且平台仍启用的模板链接均可继续访问；二维码直接包含当前模板域名和租户识别码，因此切换模板或模板域名后需要重新保存二维码。为保障安全，从未选择过的复制站点以及平台紧急停用的模板仍会被拒绝。若您在升级前切换过模板，旧链接仍提示来源不匹配，请联系平台客服登记原模板。

## 验收重点

- 同一租户先保存 `wxmb5`，再保存 `dymb1`，两个真实站点都能新建会话。
- 当前模板生成的访问令牌不能拿到另一个已批准模板复用；客户端会安全刷新会话。
- 未批准域名仍返回 `CLIENT_ORIGIN`，达到阈值后才发送来源异常告警。
- 超级后台取消某个旧模板勾选后，该旧站立即停止新会话访问。
- 全局紧急停用模板后，即使它在租户历史名单中也不能访问。
