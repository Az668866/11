# 拓界云客服修复与安全检查报告

日期：2026-08-20

## 本次完成

1. 修复语音、视频通话接通后约 2 秒自动挂断。
   - 原因是浏览器进入 `disconnected` 或 `failed` 后只允许一次 ICE 重连，最短约 1.2 秒就会主动结束通话。
   - 现在短暂断网不会主动挂断；通话会保留并按 2～20 秒渐进间隔持续重建 ICE。
   - 已接通通话遇到连接计时器时只显示“网络波动，正在持续恢复通话”，不会执行挂断。
2. 加强大陆和复杂 NAT 网络兼容。
   - Cloudflare TURN 与静态 TURN 备用地址会合并下发，不再互相覆盖。
   - Render 建议同时配置 UDP 3478、TCP 3478 和 TLS/TCP 443 三种 TURN 地址。
3. 快捷语和自动回复支持图片。
   - 支持文字加图片、仅图片、默认自动回复图片。
   - 图片统一转为 WebP，最大 8MB，最长边 1600px。
   - 素材按租户隔离；未作为消息发送前只能由当前租户后台读取。
   - 访客不能伪造 `assetId` 发送后台素材。
   - 七天后自动清理未保存、未发送、未引用的孤立图片。
4. 更新通话界面。
   - 用户端和租户端均为全屏沉浸式布局。
   - 新增玻璃控制台、放大触控区、弱网状态提示、视频小窗和键盘焦点样式。
   - 桌面 1294×864、手机 390×844 检查均无横向溢出。
5. Telegram 机器人发卡内容按要求调整。
   - 只展示普通卡密、卡密类型和首次登录后有效时长。
   - 发卡消息与复制按钮均不再展示超级卡密或设备上限。
6. 其他修复。
   - 修复旧数据库迁移可能覆盖新消息素材约束的问题。
   - 修复自动回复文字和图片时间顺序不稳定的问题。
   - 阻止回复预设图通过公开素材接口直接读取。
   - 将存在高危公告的 `nanoid 3.3.17` 覆盖至 `3.3.18`。

## Render 上线必须检查

```env
CLOUDFLARE_TURN_KEY_ID=你的Cloudflare TURN Key ID
CLOUDFLARE_TURN_KEY_API_TOKEN=你的Cloudflare TURN API Token
CLOUDFLARE_TURN_TTL_SECONDS=86400

# 大陆线路建议配置独立备用 TURN，三个地址用英文逗号分隔
WEBRTC_TURN_URLS=turn:turn.example.com:3478?transport=udp,turn:turn.example.com:3478?transport=tcp,turns:turn.example.com:443?transport=tcp
WEBRTC_TURN_USERNAME=你的TURN用户名
WEBRTC_TURN_CREDENTIAL=你的TURN密码
```

只改前端无法保证大陆网络成功率。至少要有一个从中国大陆可稳定访问的 TURN 节点，并开放 UDP/TCP 3478 与 TLS/TCP 443。Cloudflare TURN 可继续使用，静态 TURN 会作为并行备用。

## 上线顺序

1. 先在 Render 补齐或确认 TURN 环境变量，再部署后端包。
2. 等健康检查和数据库迁移完成后，部署租户后台与全部用户端 Netlify 包。
3. 使用大陆移动、联通、电信各至少一张 SIM 卡，分别测试 Wi-Fi、4G/5G、Wi-Fi 与移动网络切换。
4. 通话中关闭网络 5～10 秒后恢复，确认界面显示持续恢复且不自动挂断。
5. 在快捷语、关键词自动回复、默认自动回复中分别验证文字加图和仅图片。
